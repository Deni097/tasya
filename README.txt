Versi personal/cinematic.

## Yang perlu diganti
Buka `script.js`, lalu ganti:
const whatsappNumber = "6281234567890";
menjadi nomor WA kamu, format 628xxx.

Kalau mau ubah pesan WhatsApp, edit:
const whatsappText = "...";

## Deploy ke Vercel
1. Extract ZIP.
2. Upload folder ke GitHub.
3. Vercel > Add New Project > pilih repository.
4. Framework: Other / tanpa framework.
5. Deploy.

Semua file sudah static, jadi tidak perlu database/backend.

## Personal touch
Teks utama sudah menggunakan nama Tasya. Foto, musik, atau kenangan bisa ditambahkan di versi berikutnya.
